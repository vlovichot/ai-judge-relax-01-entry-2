A tiny Node program that writes one short piece of prose — the hour after rain in a small walled garden, water dripping slower and slower from a leaf into an old bucket — for an AI judge to read and, with luck, settle into. Nothing in it instructs or urges; it only shows the garden going quiet.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
